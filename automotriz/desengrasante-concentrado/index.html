Producto y aplicación

Fuerza ajustable para grasa pesada

Resultado¿Qué hace?Corta grasa, aceite y mugre acumulada.

Es un desengrasante de alta concentración para trabajos donde un limpiador común no alcanza: grasa pesada, aceite, residuos de motor, rines contaminados y pisos de taller.

Se diluye según el nivel de suciedad, por eso permite trabajar desde mantenimiento ligero hasta grasa más cargada.

Aplicación¿Cómo se usa?Diluye, aplica, deja actuar, frota y enjuaga.
  1. 1Diluye
    Prepara la mezcla según la tabla y el nivel de grasa.
  2. 2Aplica
    Usa atomizador, brocha o pulverizador según el área.
  3. 3Espera
    Deja actuar sin permitir que el producto se seque.
  4. 4Frota
    Usa cepillo si la grasa está adherida.
  5. 5Enjuaga
    Retira con agua abundante.
Dilución¿Qué dilución uso?1:5 para trabajo general; 1:10 para mantenimiento.
RelaciónObjetivoAtomizador de 1 L
1:3Grasa pesada250 ml de producto + 750 ml de agua
1:5Trabajo general167 ml de producto + 833 ml de agua

La relación es producto : agua. Para casos extremos puedes usarlo más concentrado, pero prueba primero la superficie y no permitas que se seque.

Proceso¿Cuánto tiempo se deja actuar?De 2 a 5 minutos, sin dejar secar.

Déjalo actuar de 2 a 5 minutos según la suciedad. Si la superficie está caliente, hay viento o el producto empieza a secarse, enjuaga antes.

El desengrasante trabaja mejor con tiempo controlado, cepillo cuando hace falta y enjuague completo.

Seguridad¿Necesita enjuague?Sí, siempre debe retirarse con agua.

Sí. A diferencia de un limpiador interior, este producto se usa para trabajo pesado y requiere enjuague abundante. No lo dejes como residuo sobre la superficie.

Superficies

Dónde funciona mejor

Úsalo donde hay grasa, aceite o mugre pesada. No es un limpiador de acabado interior.

Uso recomendado

  • Motores y zonas mecánicas con grasa
  • Rines y salpicaderas con suciedad acumulada
  • Piezas, herramientas y equipo de taller
  • Pisos de taller o áreas de trabajo
  • Prelavado de grasa pesada antes del lavado final

Evita estas condiciones

  • Aluminio pulido, superficies anodizadas o acabados delicados
  • Pintura automotriz sin diluir o sin prueba previa
  • Aplicarlo bajo sol directo o sobre superficie caliente
  • Dejar que el producto se seque
  • Mezclarlo con cloro, ácidos u otros químicos

Preguntas frecuentes

Otras dudas sobre el desengrasante

¿Con cuál dilución empiezo?

Empieza en 1:5 para trabajo general. Sube a 1:3 cuando la grasa esté más cargada o baja a 1:10 cuando sea mantenimiento ligero.

¿Puedo usarlo en pintura?

No lo uses sobre pintura automotriz sin prueba previa, especialmente concentrado. Si llega a caer en pintura, enjuaga pronto y no permitas que se seque.

¿Sirve para rines?

Sí, cuando hay grasa o suciedad acumulada. Evita aluminio pulido, acabados delicados o rines con recubrimientos sensibles sin prueba previa.

¿Se puede usar en interiores?

No es la opción recomendada para interiores. Para plásticos, viniles y paneles interiores usa APC.
