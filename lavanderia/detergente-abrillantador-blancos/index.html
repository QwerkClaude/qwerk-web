Qué es

Es un detergente con abrillantador de blancos para el lavado de cargas de ropa blanca. Está pensado para lavanderías y negocios que requieren una opción específica para este tipo de prendas.

Modo de uso

  1. Separa las prendas blancas de las prendas de color.
  2. Dosifica según el peso y nivel de suciedad de la carga.
  3. Agrega el producto al compartimento de detergente o al sistema de dosificación.
  4. Utiliza el ciclo apropiado para las prendas.

Sigue siempre las indicaciones de cuidado de cada prenda y evita mezclar prendas de color con la carga blanca.
